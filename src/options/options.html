隐私说明

  • 所有设置与 API Key 仅保存在本机浏览器的本地存储中，不会上传到任何服务器。
  • 待翻译的文本会直接发送到你所选服务商的接口，扩展本身不经过任何中转服务器。
  • 本扩展不收集统计数据、不做用户画像，也不加载远程字体、图片或脚本。
  • 内置术语表随扩展打包，可离线使用「仅术语词典」服务。

恢复默认设置会清空已保存的 API Key、自定义术语与站点排除列表。
